# Genkit JavaScript Framework

Genkit is an open-source AI framework by Google for building AI-powered applications in Node.js. It provides a unified, composable API for generating content from LLMs, defining tools, building observable workflows, managing prompts, and integrating with 20+ model providers and infrastructure services.

- [Core Packages](/core/) - Framework packages: genkit, @genkit-ai/ai, @genkit-ai/core
- [Core Concepts](/concepts/) - Actions, flows, generation, tools, prompts, middleware, plugins, and more
- [Plugins](/plugins/) - Model providers, deployment targets, vector stores, interop adapters
- [Telemetry](/telemetry/) - OpenTelemetry tracing, metrics, and monitoring

**Monorepo root:** `source-code/genkit-js/`
**Language:** TypeScript (ES2022, NodeNext modules)
**Package manager:** pnpm
**Packages:** 20+ (3 core + 20 plugins + 32 test apps)
