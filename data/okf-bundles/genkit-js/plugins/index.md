# Plugins

Genkit ships with 20+ plugin packages organized into categories:

- [Model Plugins](/plugins/model-plugins.md) — LLM providers (Gemini, Claude, GPT, Ollama, etc.)
- [Deployment Plugins](/plugins/deployment-plugins.md) — HTTP server frameworks and cloud targets
- [Vector Store Plugins](/plugins/vector-store-plugins.md) — Vector databases for RAG
- [Interop Plugins](/plugins/interop-plugins.md) — MCP, LangChain integration
- [Safety, Evaluation & Monitoring](/plugins/safety-evaluation.md) — AI safety, RAG evaluation, and GCP monitoring/telemetry
