| Plugin | Package | Purpose |
|---|---|---|
| Express | `@genkit-ai/express` | Serve flows as Express.js endpoints |
| Fastify | `@genkit-ai/fastify` | Serve flows as Fastify endpoints |
| Fetch | `@genkit-ai/fetch` | Web Fetch API handlers (Cloudflare Workers, Bun, Deno) |
| Next.js | `@genkit-ai/next` | Next.js App Router integration (server + client) |
| Firebase | `@genkit-ai/firebase` | Firebase Auth, Firestore, Cloud Functions integration |
